# bubbles-tui

Terminal UI writer tool for the [`bubbles-dialogue`](../bubbles-dialogue) runtime.

A keyboard-driven TUI that lets dialogue and story writers play their `.bub`
scripts, inspect runtime errors, and step back through a session while
iterating on content.

See the [Bubbles guide](https://viezevingertjes.github.io/bubbles/) for the
underlying language and runtime.
